# Dana S. Scott — Paper Archive

This repository is Dana S. Scott's paper archive, assembled by Brian G. Milnes for
Professor Scott. It collects the published papers, lecture notes, manuscripts, and
book-length items of Dana Scott's bibliography as PDFs, together with the source
bibliography and a running record of which items are still missing.

Scott is a Turing Award laureate (1976, with Michael Rabin) and University Professor
Emeritus at Carnegie Mellon. The work here spans 1955–2025: model theory and set
theory, automata, modal and intuitionistic logic, domain theory and denotational
semantics, topos theory, and machine-checked mathematics in Isabelle/HOL.

## Naming convention

`Authors-YYYY-Title-Words.pdf`, where `Authors` is the hyphen-separated surname list
in publication order and `YYYY` is the publication year. Book-length items carry a
`-BOOK-<venue>` suffix and live at the top level rather than in `papers/`.

## Google Search Console verification

`google23506162df92bfdd.html` holds a Google site-verification token and is committed
at the repository root. **It cannot verify as things stand, and the cause is not the
file.** Google fetches `https://<your-site>/google23506162df92bfdd.html` and requires
the response body to be exactly the token line. Two things block that here:

1. **No site is being served.** GitHub Pages is not enabled for this repository
   (`has_pages: false`). There is no host answering that path, so the fetch 404s.
2. **`github.com` is not a verifiable property.** Even with the file browsable at
   `github.com/briangmilnes/ScottBibliography/blob/main/google23506162df92bfdd.html`,
   that URL returns GitHub's HTML page wrapper, not the bare token, and Search Console
   only verifies properties the requester controls — `github.com` is not one.

To make it verify, enable GitHub Pages on this repository (Settings → Pages → deploy
from branch `main`, folder `/`), then register the property
`https://briangmilnes.github.io/ScottBibliography/` in Search Console — a URL-prefix
property, not a domain property, since the domain is `github.io`. Confirm the token
is served by fetching
`https://briangmilnes.github.io/ScottBibliography/google23506162df92bfdd.html` and
checking the body is the token line, then click Verify.

Note that indexing is a separate matter from verification: without an `index.html` or
a Jekyll build, Pages will serve this `README.md` as the site's home page, and the
PDFs will be crawlable as static files under `/papers/`.
